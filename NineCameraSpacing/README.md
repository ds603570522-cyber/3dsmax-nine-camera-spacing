# 裸眼 3D · 九机位间距

九台摄影机按空间顺序排列，以第 5 台为中心，调整相邻摄影机的统一间距。只写入两侧八台摄影机的位置，所有目标点保持原位。目标摄影机仍看向原目标点，视角方向会随位置变化。

## 使用

1. 在 3ds Max 中运行 `Install.ms`，或直接运行 `NineCameraSpacing.ms` 临时使用。
2. 点击“绑定场景中的 9 台”；场景有其他摄影机时，选择需要的九台，再点击“绑定选中的 9 台”。选择中包含目标点也没关系。
3. 默认沿中心摄影机的本地 X 轴横向排列；也可在绑定前改选世界 X / Y / Z。默认按空间位置识别中心，与点击和名称顺序无关。可在绑定前指定中心，指定的摄影机必须位于排序的中间。
4. 调整“相邻间距 (mm)”或百分比滑块即可实时展开、合拢。输入值固定使用毫米，与场景显示单位无关。零间距会让九台机身重合。
5. “当前”和下方列表显示实际距离，保留五位小数；“复制间距记录”复制时间、中心、排列轴、每对实际距离和首尾跨度，便于记录。
6. “100% 等距排列”使用绑定时的平均间距；“恢复绑定时原排列”恢复八台侧机原来的相对位置，包括原本的不等距。中心始终保持当前的位置。

## 再次打开

1.1.0 起，使用顶部菜单栏 **插件 → 九机位间距** 打开工具。原生菜单扩展会在每次启动 Max 时自动加载，不创建工具栏按钮或额外停靠面板。

`NakedEye3D` 分类宏仍然保留，可用于设置快捷键。安装器会移除旧版主工具栏的九机位按钮，并关闭早期停靠面板。其他工具栏的按钮保持原样。

关闭并重新打开面板会保留当前 Max 会话中的绑定和恢复基准。打开另一个场景或重启 Max 后需重新绑定；插件文件会保留。若在完全合拢后重新绑定，无法从位置推断左右顺序，将按摄影机名称处理同位置项。

## 行为说明

- 位置公式：`中心当前位置 + 固定排列轴 × (序号 - 5) × 相邻间距`；首尾跨度为相邻间距的八倍。
- 绑定不修改场景。插件不修改摄影机目标点、焦距、FOV、镜头偏移、旋转控制器、父子关系或渲染设置。
- 本版本用于静态机位调校，不接管已有位置动画、约束、列表、脚本控制器或共用位置控制器。遇到冻结、位置锁定，以及会带动摄影机/目标点的父子链接会停止并显示原因。
- 每次间距变化和恢复都可用 Max 的撤销操作还原。实际数值会自动刷新，撤销后以“当前”和每对间距列表为准。
- 恢复基准保存在当前 Max 会话内，重新绑定会以当时的位置建立新基准。插件不自动保存 `.max` 文件。

适配与验证：3ds Max 2026 中文版，标准目标摄影机和自由摄影机。

共用“插件”菜单的固定 GUID 是 `bc206b8c-d20e-477d-b837-521ade67b012`。后续菜单扩展应在 `#cuiRegisterMenus` 回调中用 `GetMenuById` 查找它；若不存在则以同一 GUID 创建，再加入各自的菜单命令。每个命令使用不同且固定的 GUID，不要删除或重建共用父菜单。菜单也会出现在 Max 原生菜单编辑器中。
